## Executive summary

- **Overall fidelity: ~90%.** The Stage 1–8 + Phase 9 wizard plus the cinematography engine are implemented end-to-end. Library minimums all pass the load-time validator. Verbatim copy (Stage 1.0 welcome, Stage 1.5 confirmation framing, stage banners) is faithful. The Higgsfield → OpenAI/fal swap is documented in `architecture.md`. Likeness sentence and HARD exclusions appear in every render-prompt builder.
- **Top 3 misses (user-visible):**
  1. **Stage 4.5 caption-container picker is entirely absent.** The 5 memorial containers (`engraved_stone_plaque`, `polaroid_border`, `postcard_back`, `embroidered_sampler`, `pressed_flower_bookmark`) ship in v1.3 of the spec as first-class library entries with a Stage 4.5 picker UI. The spec describes a real skip-ahead (photo + name + species/gender + traits + favorites, defaults for everything else); the implementation treats the question as decoration.

- **Top 3 standouts:**
  1. **Cinematography engine is properly built.** All 5 consistency-pass rules (lens range, move variety, calm bookends, caption-readable, ambient continuity) execute deterministically in `consistency-pass.ts`. DP overlay biases run before the consistency pass (correct ordering per spec). Per-format lens ranges match the spec table exactly.

  3. **State machine + URL-driven wizard cover every stage 1–8 + Phase 9.** `state.ts` is a pure reducer with discriminated-union events; `legalNextStages` is derived from the reducer itself so the server-side PATCH validator and the client agree on transitions. Tag set covers `intake_*`, `character_sheet_*`, length/aspect, `curator_*`, `format/theme/style`, beat sheet, storyboard, words, card preview, cinematography, video, assembly, eulogy, delivery.
